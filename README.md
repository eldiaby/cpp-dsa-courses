# C++ & DSA Courses

This repository contains all my projects and exercises from the C++ course and Data Structures & Algorithms course.

## Structure

- `cpp-course/` : C++ course projects, organized by sections
- `dsa-course/` : Data Structures & Algorithms projects, organized by sections
- `.vscode/` : VS Code configuration files (tasks, launch, extensions)

## Build & Run

For simple programs, compile using g++:
```bash 
  g++ main.cpp -o main
  ./main
```

For projects with multiple files, compile all together:
```bash
g++ *.cpp -o app
./app
```


Notes

    This repository ignores build files, logs, and temporary files.

    Follow section folders for each lesson/project.
